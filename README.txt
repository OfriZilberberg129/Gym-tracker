האימונים שלי — יומן מעקב לאימוני כוח (גרסה לנייד)

מה יש כאן:
- index.html: אפליקציה מותאמת לנייד, ללא חיבור לשרת
- manifest.webmanifest, sw.js, icons: מאפשרים להוסיף את האתר למסך הבית ולהשתמש בו גם כשהרשת אינה זמינה לאחר טעינה ראשונה (אם האתר פורסם ב-HTTPS)

דרך מומלצת לשימוש קבוע בטלפון:
1. חלץ את קובץ ה-ZIP לתיקייה.
2. פרסם את תוכן התיקייה באחסון סטטי HTTPS (למשל GitHub Pages או Netlify Drop).
3. פתח בטלפון את הקישור הקבוע שקיבלת.
4. ב-iPhone: בתפריט שיתוף ב-Safari בחר "הוסף למסך הבית".
   באנדרואיד: בתפריט Chrome בחר "התקנת אפליקציה" / "הוסף למסך הבית".
5. התחיל להקליד חזרות ומשקלים. הכל נשמר אוטומטית בדפדפן המכשיר.

לבדיקה במחשב: פתח את index.html ב-Chrome או Edge. השמירה בקובץ מקומי עשויה להתנהג אחרת בדפדפנים מסוימים.

אזהרה חשובה: אין סנכרון בין מכשירים. קובץ הגיבוי בפורמט JSON הוא הדרך לשחזר או להעביר את היומן. ייצוא CSV מיועד לפתיחה באקסל אבל אינו קובץ שחזור מלא.

האפליקציה מבוססת על תוכנית: שלישי פוש, רביעי פול, שישי רגליים, שבת פלג גוף עליון. אפשר לרשום אימונים בתאריכים אחרים ולהוסיף תרגיל לאימון ספציפי.
